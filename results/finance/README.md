# Finance run manifests and historical results

For the Finance results in arXiv:2609.01836v1, start with the
[Finance redesign result guide](../finance_redesign/README.md).

The final runs have names containing `finance-redesign-final-`; the release declaration links
all 33 manifests by hash. Their raw JSONL files are currently missing.

The `finance_v1__*`, `phase2_finance_replacement*`, and older transfer summaries in this directory
describe superseded Finance constructions. They are preserved as historical artifacts and must
not be used to reproduce the paper's redesigned Finance tables.

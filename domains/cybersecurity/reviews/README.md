# Cybersecurity review artifacts

The `benchmark_v1` packet contains 128 blinded authorization decisions and 64 blinded
challenge-attractiveness rankings. `benchmark_v1.json` records the completed review and maintainer
approval used by the frozen `cybersecurity_v1` release.

The private mapping is retained so the packet can be audited against the deterministic oracle and
presentation without exposing labels in the blinded files.
